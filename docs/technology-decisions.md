# Technology and licensing decisions

| Candidate | Decision and trade-offs |
| --- | --- |
| [Androguard](https://pypi.org/project/androguard/4.1.4/) | Use the reviewed 4.1.4 Python API for binary manifest, resource, and selected DEX facts on CPU. The branch advertises a separate 5-series API. The 4-series code has an [Apache 2 notice](https://github.com/androguard/androguard/blob/v4.1.3/LICENCE-2.0). Audit transitive Python packages and parser updates. |
| [apksigner and SDK Build Tools](https://developer.android.com/tools/apksigner) | Use cryptographic verification from a Java subprocess. Compose uses the Debian package, while the Android SDK jar supports local Windows/Linux use. The [AOSP apksig license](https://android.googlesource.com/platform/tools/apksig/+/refs/heads/main/LICENSE) covers source. Google SDK distributions have [additional SDK terms](https://developer.android.com/studio/terms). Review redistribution of tools and bundled notices. |
| [MobSF](https://github.com/MobSF/Mobile-Security-Framework-MobSF/blob/master/LICENSE) | AGPLv3 broad analysis platform with dynamic-analysis integration. Avoid embedding it in this release given network-use source obligations for modified deployments and wider resource/surface footprint. |
| [JADX](https://github.com/skylot/jadx/blob/master/LICENSE) and [Apktool](https://github.com/iBotPeaches/Apktool/blob/main/LICENSE.md) | Apache 2 source licenses. Useful Java-based decompilation and resource tooling when investigators require it. Full decompilation or reconstruction adds CPU, disk, and timeout obligations for this scan workflow. |
| [APKiD](https://github.com/rednaga/APKiD) and [YARA](https://github.com/VirusTotal/yara/blob/master/COPYING) | APKiD includes GPL licensing notices, with separate rule eligibility to verify. YARA's engine has a permissive BSD license. Third-party rules require individual provenance, review, runtime bounds, and redistribution permissions. Core scans use explicit local rules. |
| [FastAPI](https://github.com/fastapi/fastapi/blob/master/LICENSE), [Pydantic](https://github.com/pydantic/pydantic/blob/main/LICENSE), [SQLAlchemy](https://github.com/sqlalchemy/sqlalchemy/blob/main/LICENSE) | MIT licenses. Python typing, JSON validation, and cross-dialect queries. Pin direct versions and run compatibility tests. FastAPI supplies OpenAPI. |
| [PostgreSQL](https://www.postgresql.org/about/licence/), SQLite, [Alembic](https://github.com/sqlalchemy/alembic/blob/main/LICENSE), [Redis](https://redis.io/legal/licenses/), and [Celery](https://github.com/celery/celery/blob/main/LICENSE) | PostgreSQL license and SQLite public-domain terms are operationally suitable. SQLAlchemy schema versions keep the initial migration small. Alembic is MIT and a future option for more complex schema changes. A DB-backed queue avoids redundant data services. Redis terms vary with version. Celery has a BSD license and adds broker operations. Review Psycopg's [LGPL terms](https://github.com/psycopg/psycopg/blob/master/LICENSE.txt) and corresponding requirements for distribution. |
| [Next.js](https://github.com/vercel/next.js/blob/canary/license.md), [React](https://github.com/facebook/react/blob/main/LICENSE), [TypeScript](https://github.com/microsoft/TypeScript/blob/main/LICENSE.txt), [Tailwind](https://github.com/tailwindlabs/tailwindcss/blob/main/LICENSE), [shadcn/ui](https://github.com/shadcn-ui/ui/blob/main/LICENSE), and [Recharts](https://github.com/recharts/recharts/blob/main/LICENSE) | These are viable web options. Next.js, React, Tailwind, shadcn/ui and Recharts use MIT licenses, and TypeScript uses Apache 2. The same-origin dashboard uses standards-based HTML, CSS, and JavaScript so production has no Node.js runtime or JS build. Native progress elements and tables cover the required charts and reports. |
| [scikit-learn](https://github.com/scikit-learn/scikit-learn/blob/main/COPYING), [XGBoost](https://github.com/dmlc/xgboost/blob/master/LICENSE), [LightGBM](https://github.com/microsoft/LightGBM/blob/master/LICENSE), and [PyTorch](https://github.com/pytorch/pytorch/blob/main/LICENSE) | Scikit-learn (BSD) supplies the three CPU baselines. XGBoost (Apache 2), LightGBM (MIT), and PyTorch (BSD-style) add no measured benefit yet. [NumPy](https://github.com/numpy/numpy/blob/main/LICENSE.txt) provides arrays. [pandas](https://github.com/pandas-dev/pandas/blob/main/LICENSE) would simplify more complex transformations. [SHAP](https://github.com/shap/shap/blob/master/LICENSE) is MIT and useful for non-linear explanations. JSON logistic log-odds contributions are direct and executable serialization is avoided. |
| [Kotlin](https://github.com/JetBrains/kotlin/blob/master/license/LICENSE.txt), [AndroidX](https://android.googlesource.com/platform/frameworks/support/+/androidx-main/LICENSE.txt), [SAF](https://developer.android.com/guide/topics/providers/document-provider) | Kotlin and Jetpack Compose provide the native client, with Apache 2 source licenses. SAF grants per-document access. In-memory sessions avoid persistent token storage. [AGP compatibility](https://developer.android.com/build/releases/agp-8-7-0-release-notes) defines the build toolchain. |
| [ReportLab](https://pypi.org/project/reportlab/), [Pillow](https://github.com/python-pillow/Pillow/blob/main/LICENSE), and [NGINX](https://nginx.org/LICENSE) | Locally render PDFs and raster icon fingerprints. NGINX serves static assets and routes same-origin API requests. BSD-style ReportLab, HPND Pillow, and BSD-style NGINX terms are permissive with notice requirements. |
| [Docker Compose](https://github.com/docker/compose/blob/main/LICENSE), [pytest](https://github.com/pytest-dev/pytest/blob/main/LICENSE), [Playwright](https://github.com/microsoft/playwright/blob/main/LICENSE), and [Ruff](https://github.com/astral-sh/ruff/blob/main/LICENSE) | Use Compose and local test tools with direct pins and CI. Docker Desktop's product terms are separate from Compose's Apache 2 source license. pytest and Ruff are MIT. Playwright is Apache 2. Dependabot config tracks pip, npm, Gradle, Docker and Actions. Runtime type validation and Ruff cover the current baseline. |
| [pip-audit](https://github.com/pypa/pip-audit), npm audit, and [Trivy](https://github.com/aquasecurity/trivy) | Package audits help flag published advisories. A separate container checker is needed for OS packages and build images. Vulnerability databases, supported Python platforms, and results change over time. |

A project distribution license and bundled third-party notices need owner review before redistribution. This repository includes no third-party APK archives, private signing keys, or trained datasets. [Dataset status and requirements](ml.md).
